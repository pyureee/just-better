# Just Better Ping Remover

GitHub downloads include `config.json`. Toolbox auto-updates leave each installed `config.json` untouched. To publish changed defaults, copy your local `config.json` into this repository before committing and pushing.

Use these commands in game. `<ms>` and `<value>` are required inputs; `[name]` is optional.

| Command | Description |
| --- | --- |
| `pr` | Toggle Ping Remover on or off. |
| `pr on` | Turn Ping Remover on. |
| `pr off` | Turn Ping Remover off. |
| `pr block` | Toggle smooth block. |
| `pr jaunt` | Toggle smooth jaunt. |
| `pr delay <ms>` | Set artificial delay in milliseconds. |
| `pr dash <ms>` | Set dash delay in milliseconds. |
| `pr desync <value>` | Set desync tolerance. |
| `pr debug` | Toggle debug output. |
| `pr save [name]` | Save the recent log, optionally using the given name. |
| `pr tracker` | Show average jitter, delay, and chain delay. |
| `pr dc` | Toggle Priest Divine Charge emulation. |
| `pr priest s` | Toggle Priest Ishara's Lullaby emulation. |
